# Project Roadmap: Patent-Oriented Embedded Systems Innovation Pipeline (v1.0)

## 🎯 Ultimate Goal

Develop an **embedded systems project** that:

* Can be completed as a semester project.
* Demonstrates strong engineering and innovation.
* Has a realistic path toward a **patent** after further refinement.
* Could evolve into a research paper, startup, or competition-winning product.

# Ground Rules (Project Constitution)

These rules remain in effect throughout the project:

1. **Never start with a solution.** Start with a validated problem.
2. **Every decision must be evidence-based**, supported by research, patents, or engineering analysis.
3. **Novelty is preferred over complexity.** A simple but truly original mechanism is more valuable than a complicated system assembled from known parts.
4. **The semester prototype should target ₹3,000**, with **₹5,000 as the absolute ceiling** unless there is a compelling reason.
5. **STM32 should remain the primary controller** unless later analysis shows a different architecture is clearly superior for the chosen problem.
6. **Do not lock into an idea** until it has passed the patent and research landscape phases.
7. **Keep records of every decision**, including why opportunities were selected or rejected. This documentation will be valuable for presentations and any future patent drafting.

This gives us a disciplined roadmap. As we complete each phase, we'll treat its output as an input to the next one, so the project evolves based on evidence rather than guesswork.
