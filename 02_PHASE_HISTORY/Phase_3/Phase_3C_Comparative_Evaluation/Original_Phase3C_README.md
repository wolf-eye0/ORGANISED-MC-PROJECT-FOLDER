## Directory roles

Each retained concept directory uses:

- `prompts/` for deep-research and synthesis prompts;
- `research/` for independent model research and explicitly marked failed research.

Raw independent research is evidence, not authority. It must not override the Engineering Design Review, current Decision Register, approved closure memo, final architecture reports, or Phase 3C memories. Failed research is retained only for methodology traceability and must not be treated as valid concept evidence.

The concept root contains final architecture, memory, and SOP files; TrueMoist also contains its preserved historical PDR patch.
