## Concept 1 — OpenBraille

A low-cost refreshable single-cell Braille display intended to reduce the cost barrier of electronic Braille devices through simplified embedded actuation mechanisms and modular scalability.

Primary Focus

- Accessibility
- Embedded Systems
- Human-Computer Interaction

This project is NOT:

- Braille printer
- OCR system
- Screen reader
- Full-page Braille display

An embedded industrial predictive maintenance platform that continuously monitors machine vibration and applies edge intelligence to detect abnormal operating conditions before failures occur.

Primary Focus

- Predictive Maintenance
- Embedded AI
- Industrial IoT

This project is NOT:

- Wearable device
- Personal safety device
- Security alarm
- Fitness tracker
