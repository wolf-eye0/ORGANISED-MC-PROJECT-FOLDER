# Project mC — Phase History Index

This directory preserves the chronological development of Project mC.

## Interpretation rules

- Phase 1 records opportunity discovery and concept formation.
- Phase 2 records historical patent-landscape exploration.
- Phase 3A records engineering-landscape discovery.
- Phase 3B records engineering-feasibility analysis.
- Phase 3C records comparative evaluation and portfolio closure.
- Later governance, final architectures, adjudications and experiments override earlier conclusions where they conflict.
- Historical reports must not be treated as proof of novelty, patentability or implementation success.
