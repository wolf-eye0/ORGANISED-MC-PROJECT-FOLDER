# Phase 1B — Opportunity Analysis
## Patent-Oriented Embedded Systems Innovation Pipeline

Version: 1.0

Status: In Progress

---

# Objective

Phase 1B transforms the raw research collected during Phase 1A into a structured decision-making framework.

Unlike Phase 1A, this phase does NOT perform broad technology discovery.

Instead, it extracts, normalizes, clusters, evaluates, and ranks all opportunities identified by multiple independent research reports.

The objective is to identify the strongest opportunities that should advance to Phase 1C (Idea Synthesis).

# Rules

Throughout Phase 1B the following rules apply.

1. Do NOT invent project ideas.

2. Do NOT propose architectures.

3. Do NOT design products.

4. Do NOT search for implementation details.

5. Stay entirely within opportunity analysis.

6. Every conclusion must be supported by evidence from the research reports.

7. If two reports disagree, document both viewpoints rather than guessing.

---

# Opportunity Extraction

Every opportunity discovered during Phase 1A should be extracted.

Each opportunity receives:

- Opportunity ID
- Source Report(s)
- Original Description
- Domain
- Notes

Duplicates should NOT be deleted.

Duplicates should be linked together.

# Success Criteria

Phase 1B is complete only if:

✓ Every opportunity has been extracted.

✓ Duplicates have been merged.

✓ Opportunity clusters have been created.

✓ Every cluster has a structured record.

✓ Every cluster has been scored.

✓ Rankings are complete.

✓ Green / Yellow / Red categorization is complete.

✓ Top opportunities are ready for Phase 1C.

No project ideas should exist at the end of this phase.

Only evidence-based opportunity selection.

---

# Deliverable

The final deliverable is a structured Opportunity Analysis Report that serves as the single source of truth for all subsequent phases of the project.

Phase 1C (Idea Synthesis) may only begin after Phase 1B has been formally completed.
