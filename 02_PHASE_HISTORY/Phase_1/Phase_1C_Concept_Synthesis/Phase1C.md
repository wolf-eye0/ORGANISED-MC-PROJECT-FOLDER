# Phase 1C — Concept Synthesis

**Status:** Completed
**Phase Type:** Engineering Concept Development
**Depends On:** Phase 1B.5 – Opportunity Portfolio Optimization
**Output:** Ranked Engineering Project Concepts

---

# Purpose

Phase 1C transforms the optimized opportunity portfolio into high-level engineering project concepts.

This phase does not perform implementation, hardware design, software architecture, or detailed engineering.

Its purpose is to explore one project concept for each surviving opportunity and objectively determine which concepts deserve advancement into patent analysis and prototype planning.

---

# Inputs

Phase 1C requires:

- Final Optimized Opportunity Portfolio
- Survivor Opportunity Clusters
- Portfolio Optimization Report
- Opportunity Evaluation Records
- Research Gap Analysis

No eliminated opportunities shall be reconsidered.

---

# Objective

Generate one engineering concept for every surviving opportunity cluster.

Each concept must remain faithful to the originating opportunity and address the validated problem without introducing unrelated functionality.

---

# Concept Generation

For every surviving opportunity cluster produce:

- Opportunity Cluster ID
- Opportunity Cluster Name
- Project Concept Title
- Problem Statement
- Existing Solution Limitations
- Why Embedded Systems Are Essential
- High-Level Innovation
- Target Users
- Expected Prototype Scope
- Estimated Prototype Cost
- Patent Opportunity Summary
- Technical Risks
- Demonstration Value
- Commercial Potential

Only high-level concepts shall be produced.

---

# Comparative Evaluation

After all concepts are generated, compare every concept using:

- Originality
- Patent Potential
- Semester Feasibility
- Budget Feasibility
- Demonstration Impact
- Embedded Systems Necessity
- Team Capability
- Commercial Potential

Rank every concept objectively.

---

# Portfolio Optimization

Select the strongest concepts based on overall engineering value.

The final number of recommended concepts shall be determined by quality rather than quota.

---

# Deliverables

Phase 1C shall produce:

- Concept Portfolio
- Comparative Evaluation Matrix
- Ranked Concepts
- Final Recommended Concepts

---

# Out of Scope

Phase 1C shall not perform:

- Patent Searches
- Prior Art Analysis
- Literature Reviews
- Circuit Design
- Hardware Selection
- Sensor Selection
- PCB Design
- Software Architecture
- Firmware Architecture
- Bill of Materials
- Detailed Implementation Planning

These belong to later phases.

---

# Completion Criteria

Phase 1C is complete when:

- One concept exists for every surviving opportunity.
- All concepts have been comparatively evaluated.
- Final recommended concepts have been selected.
- Faculty-ready abstracts can be generated.

---

# Next Phase

➡ Phase 2 — Patent Landscape Analysis

Objective:

Validate the novelty of the selected concepts through systematic prior-art and patent analysis before committing to prototype development.
