# Project mC — Concept Portfolio Index

## OpenBraille

- Frozen semester identity: one macro-scale six-dot Braille cell.
- Current baseline: six SG90-class servos, eccentric cams, guided vertical pins, ESP32 direct PWM and external regulated power.
- Current MVP patent status: conventional prototype; no filing claim.
- Future research direction: VPD-C7 remains hypothetical and requires new design and experimental evidence.

## VibeGuard

- Frozen semester identity: one rigidly mounted tri-axis accelerometer, ESP32, guarded motor/fan rig and local evidence output.
- Minimum classifier: RMS plus persistence.
- FFT/band features and ordinary Mahalanobis are comparisons, not mandatory invention claims.
- Dense-floor attribution and PIRG are post-semester research only.
- Current MVP patent status: conventional prototype; no filing claim.

## TrueMoist

- Frozen identity: local compensation for a low-cost analog capacitive soil-moisture probe using measured temperature and a controlled salinity-treatment code.
- The validated design uses controlled experimental runs and gravimetric reference measurements.
- It is not a live-EC meter, irrigation controller, cloud platform, multi-soil system or online-adaptive learner.
- No standalone verified pre-build patent-case simulation was located in the controlled inventory used for this workspace.

## Selection boundary

This directory preserves all three serious Phase 3C concepts. Folder placement does not constitute a vote, teacher authorization or final implementation selection.
