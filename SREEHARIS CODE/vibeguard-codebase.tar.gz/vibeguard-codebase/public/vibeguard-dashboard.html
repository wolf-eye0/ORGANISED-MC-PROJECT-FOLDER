Signal path

  1. ADXL345 measures three-axis acceleration.
  2. ESP32 computes per-window RMS, vector RMS, peak and crest factor.
  3. USB serial carries packets to the local bridge.
  4. WebSocket forwards normalized telemetry to this browser.
