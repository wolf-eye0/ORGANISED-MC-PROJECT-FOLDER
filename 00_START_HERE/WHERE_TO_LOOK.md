## I need to understand what Project mC currently is

Open the [Final Selection and Phase 4 Entry Memo](../07_SEMESTER_EXECUTION/01_Selected_Project/Project_mC_Final_Selection_and_Phase4_Entry_Memo.md) first, then [Decision Register v1.3](../01_GOVERNANCE_AND_CONTROL/02_Decision_Registers/Project_mC_Decision_Register_v1.3.md). The memo states the current transition concisely; the register preserves the full controlled decision history.

Current state: **VibeGuard is final, Phase 3C is closed, Phase 4 is open.** The teacher delegated concept choice to the team; the team selected VibeGuard. This is not a patentability conclusion.

## I need to understand VibeGuard before working on it

Start with the [VibeGuard Team Orientation and Project Primer](../07_SEMESTER_EXECUTION/01_Selected_Project/CURRENT/VibeGuard_Team_Orientation_and_Project_Primer.md). It is designed to orient all five members to the Level-1 architecture, roles, evidence rules, safety and project boundaries.

For formal Phase 3C technical sources, use:

- [Final Architecture Report](../03_CONCEPT_PORTFOLIO/VibeGuard/01_Final_Architecture/Phase3C_VibeGuard_Architecture_Report_Final.md)
- [Final Memory](../03_CONCEPT_PORTFOLIO/VibeGuard/01_Final_Architecture/Phase3C_VibeGuard_Memory_Final.md)
- [Final SOP](../03_CONCEPT_PORTFOLIO/VibeGuard/01_Final_Architecture/Phase3C_VibeGuard_SOP_Final.md)

Do not substitute old Phase-1C spatial-isolation/bearing-fault descriptions for the current one-sensor Level-1 semester system.

## I need to know what to do next

Use the [Semester Execution Playbook](../07_SEMESTER_EXECUTION/01_Selected_Project/CURRENT/VibeGuard_Semester_Execution_Playbook.md). It controls the staged path from Phase 4A through component acceptance, bring-up, integration, final hardware/configuration freeze, locked validation, demonstration and archive.

## I need to buy hardware

Use the [Procurement, Component Acceptance and Lab Setup Checklist](../07_SEMESTER_EXECUTION/02_BOM_and_Procurement/CURRENT/VibeGuard_Procurement_Component_Acceptance_and_Lab_Setup_Checklist.md).

**THIS is the current primary purchasing/BOM authority for Phase 4.** For the complete market study, vendor investigation (Robu.in / Robocraze) and Kerala delivery logistics, refer to [`VibeGuard_Hardware_Procurement_Plan.docx`](../07_SEMESTER_EXECUTION/02_BOM_and_Procurement/CURRENT/VibeGuard_Hardware_Procurement_Plan.docx). Seller stock, delivery, price, electrical documentation and exact module identity must still be rechecked on the order date. A price snapshot is not permanent approval.
